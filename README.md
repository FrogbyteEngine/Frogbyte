# Frogbyte

Frogbyte is an experimental, data-oriented 3D game engine written in Rust.

The project exists to study game-engine architecture in depth, retain control over performance-sensitive systems, and eventually support games with unconventional visual and technical directions.

> [!WARNING]
> Frogbyte is in an early research and foundation phase. APIs, architecture, file formats, and behavior may change without notice. The project is not ready for production use.

## Project status

Frogbyte is currently pre-release. No package provides a stable public API or compatibility guarantee unless a document explicitly states otherwise.

Known experiments and unfinished work should be labelled as such. Experimental code does not become part of the accepted architecture merely because it exists in the repository.
